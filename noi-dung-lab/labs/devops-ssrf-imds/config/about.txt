FinPortal web application to force the server to read a mock Instance Metadata
Service (IMDS), steal the temporary credentials of an IAM role, then use those
credentials to access cloud object storage (MinIO) and retrieve the flag.

allowlist, IMDSv2 enforcement (token + hop limit), and least-privilege
recommendations. Level: Advanced.
